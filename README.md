⌨️ Typing Game

빠르게 나타나는 문자를 입력하며 타이핑 속도와 정확도를 겨루는 웹 기반 타이핑 게임입니다.

제한 시간 20초 동안 최대한 많은 문자를 정확하게 입력하고 높은 점수를 획득해보세요!

✨ Features

⏱️ 20초 타이핑 게임

게임 시작과 동시에 20초 카운트다운

제한 시간이 끝나면 자동으로 게임 종료

⌨️ 랜덤 문자 입력

현재 입력해야 할 문자를 화면 중앙에 표시

게임 진행에 따라 알파벳과 숫자가 등장

💯 점수 시스템

정답 입력 시 점수 획득

오답 입력 시 점수 차감

연속 정답에 따른 콤보 보너스 적용

🔥 콤보 시스템

연속으로 정답을 입력하면 콤보 증가

오답 또는 입력 시간 초과 시 콤보 초기화

게임 종료 후 최고 콤보 확인 가능

📈 레벨 시스템

정답을 5개 맞힐 때마다 레벨 상승

레벨이 올라가면 입력 가능한 문자의 범위가 확장

🏆 최고 점수

브라우저의 localStorage에 최고 점수 저장

이전 기록보다 높은 점수를 획득하면 NEW RECORD! 표시

🥇 명예의 전당

플레이어 이름을 입력하고 게임에 참여

상위 10개의 점수를 저장하고 표시

별도의 서버 없이 브라우저 localStorage를 활용

🎨 입력 피드백

정답 입력 시 초록색으로 표시

오답 입력 시 빨간색으로 표시

남은 시간이 5초 이하가 되면 경고 애니메이션 표시

📱 반응형 UI

데스크톱과 모바일 화면을 고려한 반응형 레이아웃

🕹️ How to Play

게임 화면에서 이름을 입력합니다.

게임 시작 버튼을 클릭합니다.

화면에 표시되는 문자를 키보드로 입력합니다.

정답을 입력하면 새로운 문자가 나타납니다.

정확하게 연속 입력하여 콤보를 쌓아보세요.

20초가 지나면 게임이 종료됩니다.

최종 점수와 정답 개수, 최고 콤보를 확인합니다.

점수는 명예의 전당 TOP 10에 기록됩니다.

📊 Scoring

점수는 정답 여부와 콤보에 따라 계산됩니다.

정답
기본 점수: +10점
콤보 보너스: +2점씩 증가
최대 콤보 보너스: +20점


예를 들어 콤보가 증가할수록 한 번의 정답 입력으로 얻는 점수가 높아집니다.

오답
-5점
콤보 초기화


단, 점수는 0점 아래로 내려가지 않습니다.

📈 Level

게임 시작 시 레벨은 1입니다.

정답을 5개 입력할 때마다 레벨이 상승합니다.

정답 0~4개   → Level 1
정답 5~9개   → Level 2
정답 10~14개 → Level 3
...


Level 1에서는 알파벳이 등장하고, Level 2부터는 숫자를 포함한 문자가 등장합니다.

🏆 Leaderboard

게임이 종료되면 플레이어의 이름과 점수가 브라우저에 저장됩니다.

최대 10개의 기록을 저장

점수가 높은 순서로 정렬

브라우저의 localStorage 사용

서버나 별도의 데이터베이스 없이 동작

저장되는 주요 데이터는 다음과 같습니다.

{
  name: "Player",
  score: 120
}

🚀 Getting Started

별도의 패키지 설치가 필요하지 않은 Vanilla HTML/CSS/JavaScript 프로젝트입니다.

1. Repository Clone
git clone https://github.com/woori-won-it-yezixx/woori-won-it-typing-game.git
cd woori-won-it-typing-game

2. 실행

index.html을 브라우저에서 열거나 Live Server 등의 정적 서버를 이용해 실행할 수 있습니다.

예를 들어 VS Code의 Live Server를 사용하는 경우:

index.html
→ 우클릭
→ Open with Live Server

💾 Data Storage

이 프로젝트는 별도의 백엔드 서버나 데이터베이스를 사용하지 않습니다.

브라우저의 localStorage를 사용하여 다음 데이터를 저장합니다.

typingHighScore
typing-game-leaderboard


따라서 리더보드와 최고 점수는 현재 브라우저 환경에 저장되며, 다른 브라우저나 다른 기기와 공유되지 않습니다.
